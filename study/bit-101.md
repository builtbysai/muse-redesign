## Why he matters for this project

teaches by building: small, complete, readable sketches, each one a single

a perfect example of his method: start with the most boring possible thing (a
hex grid), apply one transformation, get something beautiful.

## Core techniques

### 1. Perlinize: flow-field displacement of grid vertices
The whole trick in one function (his code, verbatim parameters):

```
function perlinize(x, y) {
  const scale = 0.01;
  const strength = 20;
  const angle = noise.perlin2(x * scale, y * scale) * Math.PI;
  return {
    x: x + Math.cos(angle) * strength,
    y: y + Math.sin(angle) * strength,
  }
}
```

Every hexagon vertex is passed through `perlinize()` before stroking. The
noise value becomes a flow-field angle, the angle becomes an offset. Nearby
vertices sample nearby noise, so they move coherently: the grid warps like a
sheet instead of jittering like static.

**The subtle detail that matters:** he had to REMOVE the canvas translation
code first, because the noise lookup needs the exact absolute x, y of every
point. Displacement must be a pure function of position, never of draw order
or transform state. This is the kind of bug that produces "it looks random
instead of organic" and the fix is architectural, not parametric.

**Takeaway:** `perlinize()` is a general vertex shader for any tiling: squares,
triangles, hexagons, polar grids. Two dials control everything: `scale`
(feature size of the warping) and `strength` (how far vertices travel).

### 2. Hexagonal tiling as a substrate
The first post builds the plain hex grid the second one warps. Hexagons tile
without gaps and read as "natural" (honeycomb, basalt columns, turtle shells),
so warping them pushes toward the organic with very little code.

**Takeaway:** The substrate does half the aesthetic work. A warped hex grid
reads as cracked earth; the same warp on a square grid reads as fabric. Choose
the tiling for the feeling you want, then warp it.

## What it looks like (verified by local recreation)
Recreating his exact parameters (scale 0.01, strength 20, hex radius 34)
produces a mesh that reads as cracked mudflats or reptile skin: every cell
still a hexagon, all of them sheared and stretched, the whole sheet holding
together. Strength is the aesthetic dial: small values give a subtle wobble,
large values tear the mesh into near-chaos. His demos are typically minimal
black linework on white, which lets the geometry carry everything.

## Philosophy
- Teach by building: one technique per post, complete code, no mystique.
- Start boring, transform once. The beauty is in the transformation, not the substrate.
- Readable code over clever code; his snippets are meant to be retyped.

## Techniques to steal (not copy)
- `perlinize()` as a reusable vertex-warp for any tiling or point set
- Absolute-coordinate noise lookups (never noise over draw-order state)
- Warp-then-render pipeline: build the clean geometry first, displace second,
  style last
- Substrate choice as an aesthetic decision (hex = organic, square = woven)

## What NOT to do
- Do not ship a plain perlinized grid as a doodle. The warp-a-grid-with-noise
  move is well traveled. It becomes ours only with a second idea on top:
  selective rendering, fill rules driven by a second field, layering, or an
  unusual substrate.
